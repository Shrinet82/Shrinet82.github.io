Project Aegis

Autonomous Cloud Governance. An Immune System that deletes threats in real-time.

Cloud Custodian Powerpipe AWS EventBridge Steampipe

The Problem 🕸️

Cloud environments rot. "Zombie" resources (unused EBS volumes) waste money, and insecure Security Groups leave doors open ("0.0.0.0/0"). Manual audits happen once a quarter—far too slow.

The Solution 🏥

I built an **Event-Driven Immune System**. It listens to CloudTrail events in real-time. If it sees a threat (like a public S3 bucket), it triggers a Lambda to "heal" (delete/revoke) the resource instantly.

Policy as Code

# policies/security-enforcer.yml
policies:
  - name: kill-public-s3
    resource: s3
    mode:
      type: cloudtrail
      events: [CreateBucket, PutBucketAcl]
    filters:
      - type: global-grants
        permissions: [READ, WRITE]
    actions:
      - type: delete-global-grants
      - type: notify
        transport: slack
        message: "🛡️ Aegis neutralized a public bucket: {bucket_name}"
