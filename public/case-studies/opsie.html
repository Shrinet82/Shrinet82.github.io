OPSIE IDP

Self-service platform that lets developers provision AWS Infra in minutes, not days.

Backstage Terraform ArgoCD GitHub Actions

The Problem 🐢

Developers were dependent on the Ops team for everything. Creating a simple S3 bucket required a Jira ticket and a **2-day wait**, slowing down innovation and frustrating everyone.

The Solution 🚀

I built an **Internal Developer Platform (IDP)** using Backstage. It acts as a self-service vending machine where developers can click a button to provision compliant infrastructure in **minutes**.

Policy as Code

// packages/backend/plugins/rbac.ts
class OpsiePolicy implements PermissionPolicy {
    async handle(request, user) {
        // 1. Super Admin Bypass
        if (user.is('user:default/shrinet82')) {
            return { result: 'ALLOW' };
        }
        
        // 2. Developer Logic
        if (request.permission === 'catalog.entity.delete') {
            return { result: 'DENY' }; // Devs can't delete
        }
        
        return { result: 'ALLOW' };
    }
}
