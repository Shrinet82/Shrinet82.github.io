AI SRE Agent

Autonomous agent that monitors Kubernetes, detects issues, and fixes them using Groq LLM.

Python 3.10 Groq (Llama 3) Prometheus Qdrant (Vector DB) Kubernetes

The Problem 🐢

On-call engineers were wasting 50+ hours/month dealing with repetitive alerts (Pod crashes, OOM kills). Waking up at 3 AM to run `kubectl restart` leads to burnout, not innovation.

The Solution ⚡

I built an Autonomous SRE Agent that listens to Prometheus alerts, uses RAG to find similar past incidents, and executes fixes (restart/scale) in seconds—without human intervention.

The Brain Logic

async def analyze_incident(logs):
    # 1. RAG: Retrieve similar past incidents from Qdrant
    history = qdrant.search(collection="incidents", vector=get_embedding(logs))
    
    # 2. Optimized Prompt for Llama 3
    prompt = f"""
    Context: {history}
    Logs: {logs[-50:]} # Focus on last 50 lines
    
    Task: Identify root cause and recommend K8s action.
    Response must be JSON with 'confidence' score.
    """
    
    # 3. Fast Inference (~0.5s via Groq)
    return await groq.chat(prompt, model="llama3-70b")
