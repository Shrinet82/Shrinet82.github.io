"Shift Left" Security Pipeline. Catching CVEs before they hit production.

Azure DevOps Trivy Gitleaks OWASP ZAP

The Problem 🔓

Security was an afterthought ("Shift Right"). Developers would push code, and security teams would only find critical vulnerabilities (CVEs) days later during a manual audit—often too late.

The Solution 🛡️

I implemented a **Zero-Trust SSDF Pipeline**. Security checks (Gitleaks, Trivy, Checkov) run automatically on every commit. If a critical vulnerability is found, the build fails immediately.
